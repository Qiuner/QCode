# 维护决策：教程作为项目学习记录

状态：已采用，尚未实施。

## 问题

全局教程模式无法自然表达不同项目的学习进度，也容易把暂停引导与任务取消、界面卸载混在一起。

## 决定

- 教程是 Workspace 关联的 `TutorialRun`，锁定 `TutorialDefinition` 版本；教程与自由创作共享居民、Session、工具和审批。
- 首版每项目最多一条未完成学习记录，暂停仍算未完成；允许多条历史记录。
- 暂停教程只暂停引导，不卸载插件、不撤销文件修改、不自动取消任务。
- 完成后保留项目继续创作；重做默认创建新练习项目。
- 检查结果与学习掌握程度分开，保留验收依据和协助记录。

## 后果

工作台根据项目学习记录显示引导，无需全局模式开关。必须处理课程版本保留、项目准备失败和学习恢复；不能仅依赖聊天推断进度。暂不支持同项目多条未完成课程并行推进。

设计与验收见 [教程架构](../../../../docs/tutorial-architecture.md)。
