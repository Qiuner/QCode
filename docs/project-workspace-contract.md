# 项目与 Workspace 契约

Workspace 是项目工作的唯一归属边界。居民、Session、教程记录和作品都必须引用 Workspace，不能只依赖浏览器本地映射。

## 项目操作

创建项目时生成唯一目录并记录 Workspace；选择已有目录前必须由 Host 验证路径、归属和可访问性。中断的创建只能通过明确的“继续已有项目”恢复，不能默认取得目录所有权。

## 文件边界

文件读写由 Host / DSH 工具完成。世界和 Client 只传递项目标识、相对路径和展示摘要，不暴露主机绝对路径。Host 必须拒绝路径穿越、越权 Workspace 和无效 revision。

## 恢复

项目切换、刷新和重连先重新获取 Workspace 快照，再恢复居民与 Session；本地草稿只能作为未保存输入备份，不能覆盖 Host 已保存事实。
