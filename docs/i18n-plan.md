# 中英文切换施工方案

状态：实施中（第一阶段部分实现）

当前进度：DSH locale 已接入 agent-isles Web 插件；小岛右上角提供中文 / English 快捷切换；Web 主外壳、项目选择、居民入口、主要任务状态和确认面板已迁移；Godot 已接入中英文 PO 资源并同步居民、对白、状态与主要交互提示。教程、模型设置、文件面板、通知和完整 HUD 仍待迁移，真实浏览器视觉验收尚未完成。

## 目标与边界

agent-isles 提供简体中文与英文界面，并让 DSH 工作台、agent-isles Web 面板和 Godot 世界共享同一语言选择。切换后当前页面即时更新，刷新和重新启动后继续使用已保存的语言。

首期不翻译用户内容、历史消息、项目名、文件名、模型返回内容或代码；这些内容保持原样。内部居民 ID、Workspace / Session 标识、桥接事件名和本地存储键不随语言变化。

## 技术方案

- 复用 `@deepseek-ai/dsh-client-locale` 作为唯一语言状态源，不另建浏览器语言偏好。
- agent-isles Web 插件注册类型安全的 `zh` / `en` 字典，通过 DSH locale seat 向 React 根界面提供翻译函数。
- `world:init` 携带当前语言；运行中切换时通过 `world:locale` 消息同步给 Godot。
- Godot 使用 `TranslationServer` 和项目翻译资源，不在业务脚本中散落 `locale == "zh"` 分支。
- 发给模型的居民身份提示和教程指令按提交当时的界面语言生成；既有会话内容不重写。
- 持久化通知最终保存消息键与参数，显示时按当前语言渲染，避免旧通知锁定为创建时的语言。

## 实施阶段

### 第一阶段：Web 语言基础与主流程

- 接入 DSH locale 服务并注册 agent-isles 字典。
- 翻译小岛外壳、居民入口、项目选择、工作状态、模型设置和文件查看的主要界面。
- 保留设置页的 Language 选择作为权威入口；小岛快捷入口只调用同一服务。
- 增加字典键完整性、默认语言和运行时切换测试。

### 第二阶段：Godot 世界

- 扩展 Web / Godot 桥接协议，验证语言字段和切换事件。
- 建立 Godot `zh` / `en` 翻译资源。
- 迁移居民姓名与对白、交互提示、路牌、背包、种植、Toast 和 Q 状态文本。
- 验证独立 Godot 默认语言及嵌入 Web 后的即时切换。

### 第三阶段：教程、模型语义与持久化内容

- 翻译首课步骤、示例需求、错误恢复和工作叙述。
- 居民系统提示与教程模型指令按当前语言生成。
- 通知存储由渲染文本迁移为消息键与参数，并兼容读取旧记录。
- 检查英文长文案在桌面和窄屏下的换行、按钮宽度和无障碍名称。

## 验收

- 中文浏览器首次打开显示中文；英文浏览器在没有保存偏好时显示英文。
- 在设置中切换语言后，DSH、agent-isles 面板和 Godot 世界无需刷新同步更新。
- 刷新页面和重启本地服务后仍保持显式选择。
- 中文与英文均可完成选择项目、打开居民、发起任务、查看文件、处理审批和返回小岛。
- 既有会话映射、项目恢复、草稿和通知不因显示语言变化而丢失。
- 桌面及窄屏英文界面无溢出、遮挡或不可点击控件。

## 当前限制

施工进行期间可能出现 DSH 原生界面已切换而部分小岛文案仍为中文的阶段性状态；只有上述三阶段和双语浏览器验收完成后，状态才能改为“已验收”。README 的英文版本不属于应用内切换，单独安排。
