# 运行恢复契约

恢复的目标是重新连接并核对事实，不是猜测或重放未确认的任务。

| 故障 | 必须行为 |
| --- | --- |
| Client 断线 / 刷新 | 重连后获取快照和 revision，恢复当前 Workspace、居民与 Session |
| Host 重启 | 恢复持久记录并核对 DSH 执行引用；不确定结果标记为 `interrupted` |
| 请求超时 | 按 operationId 查询；没有幂等保证时不得自动重发 |
| 任务失败 | 保留失败事实和错误类别，允许用户明确发起新任务 |
| Host 崩溃 | Launcher 有界重启并记录退出原因；恢复连接后重新同步 |

恢复期间界面应显示连接或核对状态。自动恢复只恢复连接、快照和展示状态，不自动发送用户消息。
