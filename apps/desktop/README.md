# agent-isles Windows Launcher（预留）

此目录预留给未来的轻量 Windows Launcher，目前没有桌面应用实现。

Launcher 的职责将限定为：

- 启动固定版本的 DeepSeek Harness runtime 和 agent-isles Web profile；
- 等待本地 Web 服务健康后打开系统默认浏览器；
- 接收 runtime 的当前认证链接，自动建立浏览器会话；服务重启或用户换浏览器后，由应用入口再次打开有效链接，用户无需查找 token 或源码目录；
- 处理单实例、端口冲突、启动错误和所启动子进程的退出清理。

人物世界、对话、审批和 Harness 工作台继续由网页承载，不在这里复制一套桌面 UI。当前开发请使用根目录的 `corepack yarn dev:web`。

发行包需要包含所需运行时与构建资源，不要求最终用户下载源码或安装 Node/Yarn。网页不得提供公开签发本机访问凭证的接口；重新连接由本地 Launcher 持有的入口完成。在 Launcher 实现前，网页只提供真实可用的恢复指引，不展示未接通的启动器按钮。

在线部署需要独立设计账号登录、会话失效和权限隔离。当前临时认证链接与开发脚本不作为在线产品的登录方案，也尚未实现在线登录页。
