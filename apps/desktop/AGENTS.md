# 桌面启动器与发行约束

- 本目录负责 Windows 启动器、macOS Intel 便携启动器及打包验证；平台构建和使用方式见 [README](README.md)。
- 启动器只管理自己启动并拥有的服务进程树；正常退出、崩溃清理和单实例交接不得误杀其他实例或用户进程，不按通用进程名批量终止。
- 打包不得包含开发凭证、用户项目、个人配置或运行状态。安装、解压与启动验证使用独立数据目录，不覆盖现有用户数据或安装。
- Node 与原生依赖必须匹配目标操作系统及 CPU 架构。Windows 与 macOS 分别验证启动、单实例和退出清理，未执行的平台验证明确记为待验收，不用另一平台的结果代替。
- 发行产物对应明确的源码提交和版本；验证本次最终发行文件，最终上传产物生成后再计算 SHA-256。文件变更后重新核验，不能沿用旧包验证结果。
- 发布前按 [发布检查清单](../../docs/release-checklist.md) 核对，实际执行范围与未验收限制如实记录。
